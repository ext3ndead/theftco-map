# Theft & Co — GTA 6 Map (Telegram Mini App)

Interactive map of Leonida with 3,300+ places, opened from the @theftncobot Telegram bot.

- Map tiles: GTA VI map by Yanis (v17), via [GTADB](https://map.gtadb.org) — CC BY 4.0
